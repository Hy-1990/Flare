# 项目管理与实片测试

项目标题右侧提供「删除项目」。确认框显示项目名称、不可恢复的范围和项目文件下载入口；取消后未保存草稿保持原样。删除成功后自动打开剩余项目，最后一个项目删除后进入可创建的空状态，刷新不会重新生成示例项目。

删除需要匹配项目版本。排队或运行中的导出、尚在提交/运行/暂停查询/结果不确定的素材任务会阻止删除，避免丢失处理中任务的上下文。导出快照、已有 MP4 以及本地素材保留，避免破坏项目副本的共享素材。已删除原项目的失败导出禁用重新导出入口。
