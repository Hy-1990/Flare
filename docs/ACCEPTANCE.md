# Flare 本地验收

## 打开

- 浏览器访问：<http://127.0.0.1:4317>
- 服务没有运行时，双击项目根目录的 `启动 Flare.command`。
- 项目目录：`/Users/huyi/Project/cc/Flare`
- 样片：`docs/verification/sample.mp4`（30 秒，1280×720，24 fps，H.264 + AAC）

## 建议检查顺序

1. 播放「一粒咖啡的旅程」，打开声音，检查配乐与镜头变化。
2. 修改第一镜头标题，应用修改，再修改第二镜头。返回第一镜头撤销，确认第二镜头未回滚。
3. 打开风格库，检查 99 种 / 15 类、中文英文搜索、制作方式筛选。查看「白板」的原样片与规范，应用程序基础版；「水彩」则需每镜图片。再检查横竖屏和方形画幅。
4. 新建「雨的一生」示例，检查本地分镜是否保留原文。较长内容会完整分段或明确拒绝，不会静默截断。
5. 导入一张自己的 PNG/JPEG/WebP，应用后预览。
6. 导出 720p 成片。导出期间修改分镜，确认下载的成片仍使用提交时的版本。
7. 在设置中填写自己的 DeepSeek Key，测试 AI 分镜和单镜头指令修改。
8. 填写 DreamAPI Key，在确认费用后测试单镜头图片／配音。检查真实效果、延迟和账户费用。

## 已覆盖的验证

- TypeScript 与生产构建、代码格式检查。
- 核心测试覆盖持久化、版本冲突、撤销约束、长剧本保留、导入安全、密钥不回传、来源检查、导出取消／去重／恢复、供应商异常和素材覆盖保护。
- 浏览器测试覆盖编辑、撤销、风格切换、画幅持久化、快捷键、三个屏幕尺寸、模型协议模拟、实际图片和配音进入预览与 MP4。
- 实际渲染输出覆盖 1280×720 横屏、1080×1920 竖屏、720×720 方形。预览和导出使用同一渲染实现，抽帧相似度约为 0.998。
- 公共 HTTPS 图片下载路径做过实际网络检查；付费生成接口使用本地协议模拟，没有调用真实账户。

## 仍需你的真实账户验收

DeepSeek 的实际分镜质量、模型可用性，以及 DreamAPI 的实际画面／声音效果、音色可用性、延迟与费用。这些无法由本地模拟结果替代。
