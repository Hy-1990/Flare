# Flare v0.1.1

## Changes

- Added separate macOS and Windows installation, upgrade and troubleshooting instructions.
- Fixed Windows Chromium cache discovery and switched browser setup to Playwright's managed Chromium installation.
- Added `npm run doctor` to check Node.js, FFmpeg, FFprobe, Chromium launch and the production build without paid API calls.
- Added Windows npm-installed Codex/Claude entry-point discovery without invoking command-shell shims.
- Added macOS/Windows CI and a release workflow gated on automated checks. Each shipped fix now requires a patch version and English release notes.
- Included previously shipped timing-locked visual replacement, edit-impact previews, and GPT/Claude API and Codex/Claude CLI connections in the first tagged release.

## Installation

Follow [the installation guide](https://github.com/Hy-1990/Flare/blob/main/docs/installation.md). This is a source release, not a signed desktop installer. Install Node.js 22.13+ and FFmpeg 7+, then run `npm ci`, `npm run setup:browser`, `npm run build`, `npm run doctor` and `npm start`.

To upgrade, stop Flare, back up your local `.flare` directory, pull the new version and repeat those commands. Keep the backup private: it contains your settings and API keys.

## Validation

The release workflow requires unit tests, a production build, environment checks, UI tests and real MP4 export tests on both macOS and Windows. Model-provider tests use mocks and do not spend account credits. See the Actions run for the actual runner and results associated with this tag.

## Known limitations

- This is a local browser workspace. It does not include a Windows MSI/EXE installer or a macOS DMG, code signing, or an automatic updater.
- Windows ARM and older operating systems are not separately certified. Use an OS supported by the pinned Playwright version.
- Real-account GPT API, Claude API and Claude CLI validation is still pending. Codex has been tested live on macOS; Windows CLI authentication/model generation still needs user acceptance.
- On Windows, local credentials are protected by your account's filesystem ACLs, not POSIX mode 600. Use a private local folder, not a shared folder.
- Live narration generation is not yet verified. Image-assisted styles animate still images; they do not generate video clips.
