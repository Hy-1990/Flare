# Flare 界面调整

本轮以用户确认的「专业剪辑台：紧凑、信息清晰，画面占主导」为准，使用 Impeccable 的 Operate / polish 指导和 unslop 的九轮检查。保留工作流、影片内容、来源许可与 Flare 品牌。

## 原界面的问题

- 宣传式眉题占据工作区域；项目标题、状态和操作的主次不够明确。
- 过多接近的灰绿色值，使辅助文字偏淡，缺少统一主题语义。
- 风格库用同样的带框卡片包裹每项内容，留白重复，参考画面被容器分割。
- 界面用通用系统中文与 DM Sans；时间码和编号缺少一致排版。
- 中文固定在组件中，没有语言和外观偏好。

## 九轮处理

1. 间距：导航缩至 192 px、顶栏 48 px，减少预览上方占用；镜头面板保持独立，手机按阅读顺序堆叠。
2. 色彩：统一背景、面板、分隔线与三级文字语义变量；分别定义白天和黑夜，对片内画面不做反色。
3. 图标：保留 Lucide 家族；去除预览装饰角标，状态用已有图标和文字表达。
4. 文案：移除宣传眉题，窗口使用「新建」「导出」等具体任务词；制作范围与费用说明保留。
5. 字体：IBM Plex Sans Variable + Noto Sans SC Variable，时间码用 IBM Plex Mono；字体本地加载，保留 OFL 许可。
6. 布局：预览为主、分镜其次、镜头面板辅助；风格库以原样片画面为主，弱化卡片容器。
7. 细节：统一输入框、聚焦边框和操作层级；生产方式为文字标注，减少徽章背景。
8. 视觉：直接使用实际影片画面与原项目参考，无额外生成装饰图。
9. 动效：保留必要的任务状态反馈；主题切换即时生效，不让按钮颜色渐变造成短暂低对比。

## 语言与外观

右上角可选择中文 / English，及白天 / 黑夜 / 跟随系统。偏好保存在当前浏览器的 `flare.ui` 中。修改偏好不写入项目、不修改用户剧本、不翻译原版规范或样片内容。英文风格介绍使用固定上游元数据中的原始英文。界面、表单、提示及常见错误已本地化；未知服务诊断保留原文，避免隐藏故障信息。
