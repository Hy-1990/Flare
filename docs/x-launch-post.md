# Flare launch post

A script. A short film. ✨

I built Flare, an open-source tool that turns scripts into editable storyboards, lets you generate images and narration, and brings shot editing, preview and video export into one workspace.

Write a script → build a storyboard → edit each shot → export your film.

99 style references · Images & narration · MP4 + subtitles

DeepSeek for storyboards. DreamAPI for images and voice. Bring your own API keys.
